# MedML Main Application

Единое приложение, объединяющее функциональность УЗИ и цитологии для работы с пациентами, врачами, картами и диагностикой.

## Структура

Приложение включает:

- **Пациенты** (`/patients`) - управление списком пациентов и картами
- **Профиль пациента** (`/patient_profile`) - детальная информация о пациенте
- **УЗИ** (`/uzi_view/[id]`) - просмотр и анализ УЗИ снимков
- **Цитология** (`/cytology/[id]`) - просмотр и анализ цитологических исследований
- **Загрузка снимков** (`/upload_photo`) - загрузка новых снимков для анализа
- **Чат** (`/chat`) - общение с системой диагностики

## Запуск

```bash
# Из корня монорепозитория
npm run dev:main

# Или напрямую из папки приложения
cd apps/main
npm run dev
```

## Функциональность

### УЗИ
- Просмотр УЗИ снимков с аннотациями
- Анализ узлов и сегментов
- TI-RADS классификация
- Редактирование диагнозов

### Цитология
- Просмотр цитологических снимков
- Анализ клеток и кластеров
- Характеристики и вероятности
- История диагнозов

### Общие функции
- Управление пациентами
- Управление врачами
- Создание и редактирование карт
- Загрузка и обработка снимков

## Технологии
