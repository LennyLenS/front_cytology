# Отладка API запросов

## Возможные проблемы и решения

### 1. Запросы не отправляются

**Причины:**
- Токен не найден (ни в .env, ни в Redux store)
- Неправильный формат токена
- Проблемы с CORS
- Неправильный baseURL

**Проверка:**
1. Откройте консоль браузера (F12)
2. Перейдите на вкладку Network
3. Попробуйте открыть страницу с цитологией
4. Проверьте, есть ли запросы к API

### 2. Токен из .env не работает

**Важно:** В Next.js переменные окружения с префиксом `NEXT_PUBLIC_` встраиваются в бандл во время сборки.

**Решение:**
- Перезапустите dev-сервер после изменения .env файла
- Или пересоберите приложение: `npm run build`

### 3. Проверка токена

Добавьте в консоль браузера:
```javascript
console.log('Token from env:', process.env.NEXT_PUBLIC_API_TOKEN);
```

### 4. Проверка заголовков запроса

В Network tab браузера проверьте:
- Заголовок `Authorization: Bearer <token>` должен присутствовать
- Если заголовка нет - токен не установлен

### 5. Формат .env файла

Убедитесь, что файл `.env.local` находится в корне проекта `src/`:

```env
NEXT_PUBLIC_API_BASE_URL=http://109.73.201.164:8000/api/v3
NEXT_PUBLIC_API_TOKEN=your_jwt_token_here
```

**Важно:** Не используйте кавычки вокруг значения токена!

### 6. Проверка baseURL

Убедитесь, что `NEXT_PUBLIC_API_BASE_URL` указан правильно и доступен.

### 7. CORS ошибки

Если видите CORS ошибки в консоли:
- Проверьте, что сервер разрешает запросы с вашего домена
- Проверьте настройки CORS на бэкенде
